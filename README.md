<h1>Network Security Groups (NSGs) and Inspecting Traffic Between Azure Virtual Machines</h1>

- Remote Desktop
- Various Command-Line Tools
- Various Network Protocols (SSH, RDH, DNS, HTTP/S, ICMP)
- Wireshark (Protocol Analyzer)

- Windows 10 (21H2)
- Ubuntu Server 20.04
